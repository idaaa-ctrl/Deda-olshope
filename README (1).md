# Aplikasi Toko Kita (Login, Register & Katalog Produk)

Proyek web interaktif sederhana berbasis Tailwind CSS & JavaScript Murni.

## Isi File dalam ZIP
1. `login.html` : Halaman Login & Pendaftaran (Register) akun.
2. `katalog.html` : Halaman Katalog Produk dengan fitur pencarian, filter kategori, counter keranjang, dan paginasi (120+ barang).
3. `README.md` : Dokumentasi singkat proyek.

## Cara Menggunakan
1. Ekstrak file ZIP ini ke folder pilihan Anda.
2. Buka file `login.html` atau `katalog.html` menggunakan browser (Chrome, Firefox, Edge, Safari, dll.).
3. Anda bisa langsung mencoba fitur login, perpindahan form, pencarian produk, serta tombol paginasi.
